# Shree Swarup OS (TableTrack)

TableTrack Restaurant Operating System - Custom deployed and styled.

## Getting Started

To run the application locally:
1. Navigate to the `script` directory.
2. Run database migrations and seeders:
   ```bash
   php artisan migrate
   ```
3. Run the development server:
   ```bash
   npm run dev
   # or build production assets
   npm run build
   ```
